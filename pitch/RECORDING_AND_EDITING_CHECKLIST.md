# SOVRIVA Pitch Recording Checklist

## Before recording

- Start SOVRIVA with `Run-SOVRIVA.bat`.
- Use isolated demo data rather than personal exports.
- Open the dashboard at `http://127.0.0.1:8765`.
- Load the unpacked extension from the `extension` folder.
- Generate a fresh pairing code immediately before recording.
- Close unrelated browser tabs and notifications.
- Use 1920×1080 recording if available.
- Keep the browser zoom at 100% and make important text readable.

## Capture order

Record short clips separately so mistakes can be removed cleanly:

1. Opening problem card and dashboard transition.
2. Dashboard overview with demo records.
3. Import result and evidence detail.
4. Profile Drift comparison.
5. Cross-platform comparison.
6. Privacy-action verification.
7. Extension popup and pairing.
8. Mode change and independent protection controls.
9. Observation appearing in the dashboard.
10. Final dashboard-and-extension closing shot.

Do not record the pairing code or token as a reusable public credential. Blur it or use a temporary demo code and revoke the token afterward.

## Voice recording

- Record in a quiet room with the phone or microphone 15–25 cm away.
- Record the complete script in your own voice rather than using synthetic narration.
- Speak at a steady conversational pace; do not rush technical terms.
- Leave a short pause after each major idea and before the final tagline.
- Record two takes of the opening and closing.
- Keep the original audio file separate from the GitHub repository.

## Editing rules

- Keep the founder's voice as the main audio.
- Use captions for every spoken sentence.
- Keep each visual card on screen for at least two seconds.
- Use product footage for the majority of the runtime.
- Cut loading screens, failed clicks, and long API waits.
- Do not add fake counters, fake blocking results, or invented user statistics.
- Keep background music below the voice or omit it entirely.

## Final quality checks

- Runtime is between 2:00 and 3:00.
- Voice is clear on phone speakers and headphones.
- Captions match the spoken words.
- Dashboard and extension actions are visibly real.
- No passwords, cookies, request bodies, page text, pairing tokens, or personal data appear.
- The last frame shows: **SOVRIVA — Your Digital Identity. Your Control.**
